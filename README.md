# Skill Path Finder
A web application that helps users discover and follow personalized skill learning paths based on their interests and career goals.
## 🚀 Features
* Skill-based recommendations
* Personalized learning paths
* User authentication
* Clean UI with Tailwind CSS
## 🛠 Tech Stack
* React (Vite + TypeScript)
* Tailwind CSS
* Supabase
## 📦 Installation
```bash
git clone https://github.com/SriLikhithaPernedi/skill-path-finder.git
cd skill-path-finder
npm install
npm run dev
```
.env file is not included for security reasons.
